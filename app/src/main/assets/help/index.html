Apex AI

Multi-agent client · works offline for everything on this page

This page ships inside the APK. It loads from local assets, needs no network, and tells you exactly what the app can do without opening a single menu.

Getting started

  • 1. Connect a provider. Settings → pick Gemini, OpenAI, OpenRouter, Groq or any OpenAI-compatible endpoint → paste the key. It is stored in the Android Keystore.
  • 2. Install the packs. Tap Download engine packs on the empty chat screen. One tap, checksum verified, stored on this device.
  • 3. Pick an agent. Tap the mark at the top left. Single agents answer in one pass; autonomous agents use tools; team agents split the work.

Privacy

  • Your provider key never leaves the device except in the request header to the provider you chose.
  • No analytics, no telemetry, no third-party SDK that phones home.
  • Conversations are stored as JSON in this app's private storage, capped at 400 messages each.
  • The sandbox filesystem rejects any path that resolves outside its own directory.

When something goes wrong

  • The app writes a start-up breadcrumb and any crash trace to its own storage.
  • If a launch fails before the first frame, the next launch opens a recovery screen with that trace.
  • Settings → Last crash report shows the same text, and you can copy it.
